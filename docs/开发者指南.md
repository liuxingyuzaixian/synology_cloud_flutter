### 1.4 核心架构

#### 网络层
- `DsmApi`（单例）：封装所有 DSM Web API 调用，管理会话（sid/cookie），处理 119 会话失效
- `ApiClient`：通用后端请求，支持代理配置
- 请求流程：页面调用 `DsmApi().xxx()` → 内部构造参数 → `post()/get()` → 解析响应

#### 路由
- `FlyRouter` 管理全局路由
- `LoginInterceptor` 检查 `DsmApi().sid`，为空时重定向到 `/login`
- 主要路由：`/login`、主页（底部 Tab）

#### 页面导航
- `MainTabPage`：底部 5 个 Tab（首页、文件、照片、控制面板、我的）
- 使用 `IndexedStack` 保持各 Tab 状态
- `PopScope` 处理 Android 物理返回键（多选模式优先退出选择）

#### 持久化配置
- `AppPreferences`：封装 `SharedPreferences`
- 关键键：`sid`、`smid`、`host`、`port`、`account`、`password`、`servers`、`darkMode`、`webview_entries`

### 1.5 构建与部署

```bash
# 安装依赖
flutter pub get

# 运行调试
flutter run

# 构建 APK（分架构）
flutter build apk --split-per-abi --release

# 构建 iOS
flutter build ios --release
```

> 注意：`--split-per-abi` 会导致 versionCode = ABI_CODE * 1000 + BUILD_NUMBER。当前在 `release.sh` 中已处理。

## 四、开发注意事项

### 4.1 新增 DSM 接口
1. 在 `DsmApi` 中添加方法，构造参数 Map
2. 调用 `post()` 或 `get()` 方法
3. 在调用处处理 `data`/`result` 字段
4. 注意 `error.code == 119` 表示会话失效

### 4.2 自适应尺寸
- 使用 `.r`、`.h`、`.w`、`.sp` 进行尺寸适配
- 使用 `.asp`、`.aw` 进行高级适配（在 `app_adaptive.dart` 中定义）
- 在平板上需要特殊处理时使用 `MediaQuery.of(context).size.shortestSide > 600` 判断

### 4.3 页面跳转
- 新页面使用 `Navigator.push(context, MaterialPageRoute(builder: (_) => XxxPage()))`
- 全局路由使用 `FlyRouter().pushNamed(context, '/path')`
- 底部 Tab 页面使用 `IndexedStack` 保持状态

### 4.4 调试
- 在"我的"页面标题连续点击 5 次（3 秒内）可激活调试模式
- 调试悬浮按钮出现后可跳转调试页面
- 调试页面可设置代理、查看 API 请求等

### 4.5 构建
- `release.sh` 已处理 `--split-per-abi` 的 versionCode 计算
- 版本号格式：`0.0.x+y`（x 为版本号，y 为构建号）
- mine_page 中已对 > 1000 的 versionCode 取模还原原始构建号
